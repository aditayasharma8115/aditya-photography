# Aditya Photography

A photo-sharing website starter where only the admin can upload photos.

## Features
- Public home feed
- Search by title/caption/tags
- Like, share, and save buttons
- Individual public photo URLs
- Admin-only upload page
- Responsive design
- SEO-friendly metadata
- Local demo storage so it works immediately in the browser

## Run
Open `index.html` directly in a browser, or serve the folder with any static web server.

## Important
This starter is a front-end demo. For a truly public online site where photos persist for every visitor, connect the upload/storage layer to a backend such as Supabase or Firebase and protect the admin account server-side. Do not put a real admin password or private API secret in browser JavaScript.
